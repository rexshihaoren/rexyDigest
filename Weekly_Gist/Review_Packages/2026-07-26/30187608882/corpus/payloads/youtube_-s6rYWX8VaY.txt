dcode, the open source, model-agnostic coding agent, ships a new /goal command for long-running, persistent tasks. In this demo we use /goal to add native browser control to dcode itself, watch the agent work against acceptance criteria over several hours, steer it mid-run, inspect the work in LangSmith tracing, then test the finished feature live in a real browser session.
