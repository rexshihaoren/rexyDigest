Preview builds give every pull request its own temporary LangSmith deployment, so teams can test agent changes before they reach production.

This walkthrough shows how to:

- Create a preview deployment from a GitHub pull request
- Test a LangChain agent locally with langgraph dev
- Validate the deployed branch in LangSmith Studio
- Trigger a new preview revision with another commit
- Merge the pull request and automatically tear down the preview
