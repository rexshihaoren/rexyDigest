*   **Mengxiao Wang, Mahbub Alam, Kalyan Nakka, Nitesh Saxena** — Replication of Agentic Security Events: Audit and Investigation (ROGUE-AI) (Paper) — 2026-11-19 — [https://arxiv.org/abs/2611.26553](https://arxiv.org/abs/2611.26553)
    *   **TL;DR:** ROGUE-AI is a multi-agent framework that reconstructs reported LLM agent security incidents offline with matched controls, reproducing harm in 89% of 108 attempts and showing most harm stems from missed ordinary hazards rather than prompt injection, with causal hazard warnings reducing harm across five model families.
    *   **Takeaways:** ROGUE-AI replicated 89% of 108 reported agentic security incidents, enabling offline audit and root-cause attribution. Across GPT, Claude, Gemini, and DeepSeek agents, the blamed mistake occurred in 18–33% of runs versus ≤1% in controls lacking the blamed cause. 62 of 72 real-world harm incidents involved no attacker; agents followed task instructions but missed ordinary hazards like a shared production database. No-attacker replications caused more harm than prompt injection replications across all five model families. A tool-output warning that names the hazard and consequence reduced harm, while a same-length generic note did not.
    *   **Implication for Rex Ren:** A practitioner-philosopher should care because ROGUE-AI converts anecdotal AI accidents into a reproducible causal audit framework, enabling the systematic debugging and steering required for agents that act as reality-code manipulators.

*   **K. R. Jayaram, Vatche Isahagian, Aswath Vaithinathan Aravindan, Vinod Muthusamy, Punleuk Oum, Gaodan Fang, Michal Ulewicz, Gegi Thomas, Evelyn Duesterwald** — How Much Should an Agent Remember? Deployment Lessons from Self-Distilled Memory for LLM Agents (Paper) — 2026-11-19 — [https://arxiv.org/abs/2611.26361](https://arxiv.org/abs/2611.26361)
    *   **TL;DR:** IBM deployed a self-distilled memory pipeline for LLM agents, showing that the optimal amount of memory is model-dependent: strong models benefit from all learned guidelines while weaker models need a selected subset, with concrete failure modes and recommendations.
    *   **Takeaways:** The right amount of agent memory is a property of the model, not the memory itself. Strong models like DeepSeek-V3.2 keep improving with more guidelines; weak models like gpt-oss-120b peak with a small selected subset (~29). Self-distilled guidelines mined from agent trajectories ship in altk-evolve, CUGA, and watsonx Orchestrate. Documented failure modes include high-support guidelines that backfire, provenance dropped during consolidation, and silently swallowed API errors. Use AppWorld benchmarks and avoid baseline confounds when comparing memory methods.
    *   **Implication for Rex Ren:** For practitioner-philosophers treating agents as reality-code manipulators, this paper provides empirical guidance on calibrating an agent's memory as a steering mechanism: too much or too little memory changes task outcomes, and the right setting depends on the model's competence, analogous to tuning cognitive load for an embedded executor.

    *   **TL;DR:** Fast-JEPA is a latent world model planning method that improves action-sequence search by directly predicting outcomes of complete candidates, achieving higher success with lower latency than recursive rollout.
    *   **Takeaways:** Fast-JEPA reaches 96.5% average success and 2.41x faster planning than INTACT across four continuous-control tasks. It replaces recursive state rollout with direct outcome prediction for complete action sequences, decoupling success from planning latency. Introduces DynaGoal benchmark for world-model planning under distribution shift, deadlines, and response delays. Search-budget sweeps confirm the success-latency Pareto advantage holds across candidate counts and refinement depths. Code is open source, enabling direct reuse and benchmarking.
    *   **Implication for Rex Ren:** For a practitioner-philosopher, this shows how low-latency internal world models can make autonomous agents more capable under real-time constraints, though it remains a tool for agent design rather than evidence about the computability of base reality.
